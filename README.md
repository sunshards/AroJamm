## AroJamm

<br clear="left" />

**AroJamm** is a mobile app that helps tourists discover Naples through curated recommendations based on their interests. Designed for simplicity and cultural insight, AroJamm combines real-time location awareness with thematic filtering to suggest nearby landmarks and attractions.

> The name comes from the Neapolitan phrase *"arò jamm"*—meaning "Where are we going?"—used both to ask for direction and to express uncertainty.

## 🗺️ What It Does

AroJamm helps users:

- Select what they’re interested in: **Culture**, **Nature**, **Street Art**, **Theatre**, **Religion**, or **Sports**
- Instantly view and get directions to nearby places that match their preferences
- Read bite-sized, illustrated “postcards” about each place’s history and significance

## 🔧 How It Works

The current filtering system is **static**: each location is manually tagged with one or more categories. When the user selects their interests, the app displays nearby places that match those fixed tags.

## 🧪 Technologies

The app was developed entirely in **Swift**, using:


| Framework      | Purpose  |
|---------|--------|
| `SwiftUI`       | UI layout |
| `MapKit`        | Map rendering and location display |
| `CoreLocation`  | User geolocation |

## 🚀 What’s Next?

Although AroJamm was a prototype built in one week, there are several potential directions to expand:

- Dynamic filtering based on time of day or context
- Integration of user feedback and ratings
- Support for multiple languages
- Gamification elements (e.g., collectible postcards, rewards)
